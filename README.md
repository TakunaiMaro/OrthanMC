This is an app manager for Minecraft servers; it guides you step by step through a Playit proxy.

Installation:

1. Extract OrthanMC to the folder of your choice.
2. Run “OrthanMC.exe”.

- It will ask if you have existing files or if you want a clean installation of the server.
- It will install the Java required to start the server.
- It will ask if you accept the EULA.

You can add languages by editing a “.json” file and modifying the existing ones.
